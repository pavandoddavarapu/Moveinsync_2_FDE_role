# MoveInSync Play Store Ratings Diagnosis & Engineering Roadmap

An end-to-end diagnosis of the **MoveInSync Employee Commute App** (`com.moveinsync.ets`) using 100% public Google Play Store data, journey taxonomy modeling, and simulated rating gain calculations.

---

## 🔍 Key Findings (In Short)

* **The Problem:** MoveInSync holds an official lifetime rating of **4.64** (114,874 ratings), but user sentiment has severely degraded recently. The trailing 12-month average dropped to **3.82**, and the latest release (**v12.19.0**) hit **3.62** with **34.3% 1–2 star reviews**.
* **The Root Cause:** While blame is often placed on drivers or traffic, **40.5% of low-star reviews stem directly from solvable Product/Engineering defects** (vs. only 6.7% from driver/ops behavior).
* **The Top 4 Software Fixes:**
  1. **Map Camera Auto-Reset & GPS Lag (+0.0312 rating gain):** Eliminating the 30-second camera zoom reset that makes it impossible to see cab proximity.
  2. **Launch Hangs & Post-Update Freezes (+0.0164 rating gain):** Fixing cold-start launch crashes in v12.19.0 and SQLite migration issues.
  3. **Shift Cutoff Booking Lockouts (+0.0132 rating gain):** Replacing rigid cutoff failures with a grace-period queue and fixing inverted Night Shift labels.
  4. **Session Timeouts & Morning Re-logins (+0.0131 rating gain):** Adding background token refresh and biometric unlock.
* **The Intercept Anti-Pattern:** A newly added in-app post-ride rating popup without a "Skip" option in v12.19.0 blocked users, prompting angry commuters to vent directly on the Play Store.

## 🚀 Reusable Tool: How to Run

To re-scrape new reviews, re-classify incremental reviews, append snapshot history, check rating drop alerts, and re-generate the dashboard:

```bash
# 1. Install dependencies
pip install google-play-scraper pandas reportlab

# 2. Run the continuous monitor
python run.py
```

Settings (App ID, alert threshold drop of 0.1, file paths) can be edited in [`config.json`](config.json).
